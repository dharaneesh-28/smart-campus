# 🎓 Smart Campus - College Management Platform

## Problem Statement
PS-1: Smart Campus Management Platform - DevFusion 4.O Hackathon

## Description
A production-ready, full-stack web application that centralizes college management operations. Students, faculty, coordinators, and administrators can manage announcements, attendance, events, placements, assignments, and notifications through one unified platform.

## Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JWT, Google OAuth
- **Deployment:** Vercel (Frontend), Railway (Backend)

## Features
- 🔐 Multi-role authentication (Student, Faculty, Coordinator, Admin)
- 📋 Digital attendance tracking with analytics
- 📝 Assignment creation, submission, and grading
- 🎉 Event management with registration
- 💼 Placement drives with application tracking
- 🔔 Real-time notifications
- 📊 Analytics dashboards
- 👤 Profile management
- 🛡️ Role-based access control (RBAC)
- 🔒 Security: Helmet, CORS, Rate Limiting, JWT
